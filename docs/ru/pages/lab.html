PROXMOX / FIREWALL / ТЕСТЫ КЛИЕНТОВ

Моя виртуальная лаборатория firewall

Я использую Proxmox для испытания разных маршрутизаторов и межсетевых экранов, не меняя шлюз своей повседневной сети. Клиенты Windows и Linux позволяют проверять результаты с другого конца соединения.

Как я её создал

На хосте установлены Debian 13.8 и Proxmox VE 9.3.1. У каждого активного firewall свой лабораторный uplink и виртуальная LAN, к которой при необходимости подключаются тестовые клиенты. Последняя проверенная инвентаризация включает 18 виртуальных машин: тринадцать экземпляров firewall и маршрутизаторов на двенадцати платформах, два клиента Windows/Linux, а также PacketFence, OpenWISP и Taranac. Обычно во время тестов работают только две или три VM.

Firewall в лаборатории

Я работал с MikroTik CHR, pfSense CE, Sophos Firewall Home, VyOS, FortiGate VM, OpenWrt, IPFire, NethSecurity, FreeSense, DD-WRT, OPNsense и OpenFW. Две независимые гостевые OPNsense служат для разных лабораторных задач. Базовые тесты установки, управления, DHCP, DNS, NAT и отдельных перенаправлений различаются по платформам. Первоначальный набор испытаний с физическим ноутбуком охватывал одиннадцать экземпляров firewall, а не все позднее добавленные VM. Единый перечень проверок безопасности и восстановления для всех двенадцати платформ ещё не завершён.

Другие проекты Proxmox включают интеграцию со службой каталогов, доверенный HTTPS, восстановление хранилища и Intel iGPU passthrough для рабочего стола Linux. В последнем эксперименте с DD-WRT я диагностировал UEFI kernel panic и исправил постоянный шаблон GRUB. Перезагрузка теперь работает, но выключение ещё требует исследования.

Что предстоит сделать

  • Единообразное сравнение пропускной способности и задержек.
  • Негативные тесты между всеми соответствующими зонами и домашней сетью.
  • Полноценный тест восстановления текущего однодискового хранилища VM.
  • Делегирование префикса DHCPv6 виртуальному маршрутизатору через существующий лабораторный uplink только с IPv6 и отдельная изолированная тестовая точка Wi-Fi. Сама сеть только с IPv6 уже проверена на реальных клиентах Windows и Android.
