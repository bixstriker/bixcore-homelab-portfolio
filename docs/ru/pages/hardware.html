ЛАБОРАТОРИЯ

Оборудование и устройство лаборатории

Я создавал BiXCore постепенно, по возможности используя уже имеющиеся компьютеры и добавляя сетевое оборудование для решения конкретных задач. Эти системы лежат в основе проектов на сайте.

Сеть и безопасность

Шлюз OPNsense

Устройство на Intel N305 с сетевыми интерфейсами Intel X520/10GbE. Оно обеспечивает маршрутизацию, сегментацию, WireGuard, Suricata, Zenarmor, FreeRADIUS и RadSecProxy.

Управляемая коммутация

TP-Link Omada SG3210X-M2, два Grandstream GWN7721 и промышленный коммутатор Barox. Использую их для VLAN, транков, проводного 802.1X, LLDP и исследований IPv6. На Omada и Barox также проверил централизованный вход администраторов через TACACS+ и локальное восстановление доступа. Тесты администрирования коммутаторов →

Wi-Fi

Две точки UniFi U7 Pro XG с локально размещённым контроллером. Корпоративная Wi-Fi-аутентификация связана с PKI и RADIUS.

Питание и резервный канал

ИБП Eaton 3S подключён к firewall для мониторинга питания. Текущий резервный канал — Zyxel LTE5398-M904 по Ethernet в режиме IP Passthrough. 26 ноября я подтвердил физическое переключение WAN на LTE и обратно, включая автоматическое восстановление VPN и адресную очистку устаревших состояний firewall. Что я проверил →

Серверы и хранилища

Windows Server и PKI

Два контроллера домена Windows Server 2025 предоставляют Active Directory и DNS. Корпоративный CA и служба регистрации NDES работают на одном из них; это важно при планировании восстановления.

NAS

UGREEN NASync DXP4800 размещает инфраструктурные сервисы Docker, включая фильтрацию DNS, reverse proxy, приложения-контроллеры, мониторинг и приёмник событий коммутаторов. Сервисы NAS →

Тестовый хост Proxmox

Компьютер на Intel Core i7-4790K с 32 GB RAM, Debian 13.8 и Proxmox VE 9.3.1, который я использовал повторно. На нём также установлена Windows с UEFI Dual Boot.

Хранилище VM и графика

После миграции хранилища лаборатория Proxmox использует один диск ZFS на 2 TB. Intel HD 4600 передаётся в VM для экспериментов с графикой KDE. Избыточности у диска нет.

Тестовые клиенты

Основные тестовые клиенты для DHCP, NAT, проброса портов, VPN и Remote Desktop — виртуальные машины Windows и Linux. Когда проверка требует физического оборудования, использую реальные проводные и Android Wi-Fi-клиенты.
